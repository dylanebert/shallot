# Changelog

## 0.10.0

0.10 is a hard reset. Shallot 0.9 carried more features than it could keep verified, so 0.10 removes many of them and arranges the rest in layers, from the engine at the center to optional extras at the edge, so a game can replace or drop the outer ones. [`CONTRIBUTING.md`](CONTRIBUTING.md) describes the layers.

To port a 0.9.5 app, see [`MIGRATION.md`](MIGRATION.md). Changes before 0.10 are at the [`archive/changelog-pre-0.10`](https://github.com/dylanebert/shallot/tree/archive/changelog-pre-0.10) tag and in the git history.
