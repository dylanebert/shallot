# Changelog

## 0.10.0

0.10 is a foundational reset. It holds Shallot to a higher standard of verification, moves experimental features to their own packages, and arranges the engine in layers from core to optional extras. A game can replace or leave out the outer layers. [`CONTRIBUTING.md`](CONTRIBUTING.md) describes them.

To port a 0.9.5 app, run `shallot migrate` or read [`MIGRATION.md`](MIGRATION.md). Earlier history is at the [`archive/changelog-pre-0.10`](https://github.com/dylanebert/shallot/tree/archive/changelog-pre-0.10) tag.
