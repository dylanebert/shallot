# Examples

From `bun run examples:index` and `examples/*/shallot.json`; edit manifests. Use `bunx shallot dev examples/<name>`.

## Recipes

| name | description | add |
| --- | --- | --- |
| `animate-with-clips` | I want an object to bounce on a loop without writing a per-frame system. | `bunx shallot add animate-with-clips` |
| `annotate-the-world` | I want a label and an arrow in the world that follow a thing and update while the game runs. | `bunx shallot add annotate-the-world` |
| `billboards-and-sprites` | I want a progress ring over a unit that fills up and always faces the camera. | `bunx shallot add billboards-and-sprites` |
| `breakable-joints` | I want a hanger to snap when the load on it gets too heavy. | `bunx shallot add breakable-joints` |
| `compute-and-readback` | I want to run my own GPU compute over per-entity data and read the result back on the CPU. | `bunx shallot add compute-and-readback` |
| `custom-material` | I want to write my own shader for a material and for the background. | `bunx shallot add custom-material` |
| `day-night-sky` | I want a day and night cycle where the sun moves and the sky follows it. | `bunx shallot add day-night-sky` |
| `drive-a-vehicle` | I want a car I can drive with WASD. | `bunx shallot add drive-a-vehicle` |
| `first-person` | I want to walk around and look with the mouse like a first-person game. | `bunx shallot add first-person` |
| `game-loop` | I want to run my own logic every frame on the objects I tag. | `bunx shallot add game-loop` |
| `gpu-particles` | I want tens of thousands of particles simulated and drawn on the GPU without a CPU round trip. | `bunx shallot add gpu-particles` |
| `import-a-model` | I want to load a glTF file and place it in my scene. | `bunx shallot add import-a-model` |
| `joints` | I want to connect two bodies so one hangs from the other on springs or is welded to it. | `bunx shallot add joints` |
| `moving-platform` | I want an elevator that carries whatever is standing on it. | `bunx shallot add moving-platform` |
| `overlay-ui` | I want a HUD over my game that updates every frame. | `bunx shallot add overlay-ui` |
| `physics-playground` | I want to spawn a new physics object while the game runs and have it fall and land. | `bunx shallot add physics-playground` |
| `play-sound` | I want a sound that comes from a place in the world and pans as it moves. | `bunx shallot add play-sound` |
| `ragdoll` | I want a character to go limp and crumple when it dies. | `bunx shallot add ragdoll` |
| `render-to-a-terminal` | I want my scene drawn as text characters. | `bunx shallot add render-to-a-terminal` |
| `respond-to-input` | I want to move a thing with WASD and react to a click and a key press. | `bunx shallot add respond-to-input` |
| `save-and-restore` | I want to save the game and load it back later. | `bunx shallot add save-and-restore` |
| `surface-friction` | Why does my box slide off ramp instead of gripping? (check: unit/integration) | `bunx shallot add surface-friction` |
