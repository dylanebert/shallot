# Examples

From `bun run format` and `examples/*/shallot.json`; edit manifests. Use `bunx shallot dev examples/<name>`.

## Recipes

| name | description | add |
| --- | --- | --- |
| `first-person` | I want a first-person character to climb a route with a moving lift. (check: unit/integration) | `bunx shallot add first-person` |
| `loading-screen` | I want loading to stay inside a dedicated frame while my poster remains until the first scene frame is ready. (check: integration) | `bunx shallot add loading-screen` |
