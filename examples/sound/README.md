# Sound

A first-person yard with moving spatial music and a bell. Click the yard to look,
walk with WASD, aim and press E to pause/resume the speaker or ring the bell.
Escape releases the pointer; the bottom slider changes the music volume.

```sh
bun install
bun run dev
```
